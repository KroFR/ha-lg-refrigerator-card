# ha-lg-refrigerator-card
A sleek Lovelace card for LG ThinQ French-door refrigerators. Displays fridge/freezer temperature setpoints with intuitive +/- controls, door status with live indicator, Express Freeze toggle, air/water filter status, water usage, and dismissible alerts. Multi-language support (EN, FR, ES, IT, PT, DE, NL) with auto-detection from your HA profile.
